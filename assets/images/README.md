# Image assets

- `backgrounds/`: ảnh nền ứng dụng.
- `ornaments/`: rồng, phượng, khung và họa tiết trang trí.
- `icons/`: biểu tượng riêng của ứng dụng.
- `auth/`: ảnh cho đăng nhập và đăng ký.
- `chat/`: avatar và artwork Chat AI.
- `horoscope/`: hình lá số, cung và sao.
- `articles/`: ảnh bài viết.

Ưu tiên WebP cho artwork, PNG cho ảnh trong suốt và tên file chữ thường dùng dấu gạch dưới.
